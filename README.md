#  Análise de Clínica Veterinária com Pandas

Meu primeiro projeto de análise de dados com Python e Pandas.  
Usei uma base fictícia de uma clínica veterinária para praticar filtros, agregações e extração de insights de negócio.

#  Objetivo

Responder perguntas que qualquer clínica faria:
- Qual o ticket médio e o volume de consultas?
- Quais clientes mais gastam e voltam mais?
- Qual o peso de cada diagnóstico no faturamento?
- Cães ou gatos sustentam mais a clínica?
- Como cada veterinário performa?

#  Ferramentas usadas:

- Python 3
- Pandas

# O que foi praticado: 

- Criação de DataFrame a partir de dicionário
- Filtros com `==` e operador lógico `|`
- Agregações: `.sum()`, `.mean()`, `len()`
- Cálculo de percentual sobre o total

#  Principais resultados

Métrica . Valor 
| Faturamento total . R$ 3.520 |
| Nº de consultas . 19 
| Ticket médio . R$ 185,26 
| Peso da Otite . 10% da receita .
| Cães x Gatos. Cães faturam mais .
